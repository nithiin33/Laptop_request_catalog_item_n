This project, titled "Laptop Requesting Catalog Item," is focused on transforming a manual and inefficient IT support process into a streamlined, automated self-service experience.

🎯 Objective
The primary objective is to design and implement a new Service Catalog Item within the organization's existing service management platform to handle all employee requests for new or replacement laptops. This automation aims to reduce fulfillment time, minimize human error, and enhance transparency throughout the provisioning process.

💻 Technologies Used
The core of this solution is built upon the ServiceNow platform, leveraging several key modules:

ServiceNow Service Catalog: This is the primary user-facing technology. It provides the front-end form (the Catalog Item) where users input their specifications (variables) for the laptop.

ServiceNow Flow Designer / Workflow Engine: This is the core automation tool. It defines the backend business logic, orchestrating the steps from submission through approval and final fulfillment (task creation).

ServiceNow Hardware Asset Management (HAM) / CMDB: The final solution integrates with the asset database. This ensures that when the laptop is physically provisioned, the relevant Configuration Item (CI) and Asset records are automatically created or updated with the correct user and status details, maintaining data integrity.

Business Rules / Client Scripts: These are used for validation, auto-populating user data (e.g., manager, department), and ensuring a smooth user experience on the form.
